# DARE GENERATOR
A web application where each user can submit one dare. An admin reviews submissions, approves or rejects them, and the generator displays 12 random approved dare cards based on difficulty level.

## Features

- **Submission Page**: Each user can submit one dare using one-time credentials.
- **Admin Dashboard**: Review, approve, reject, tag difficulties, edit or delete dares.
- **Dare Generator**: Randomly displays 12 approved dare cards each time based on difficulty level.

## Technology Stack

- **Frontend**: HTML, CSS, JavaScript, React.
- **Backend**: Node.js with Express.
- **Database**: PostgresSQL or MySQL.

## Setup Instructions

### Prerequisites

- Node.js (v14 or higher)
- npm

### Installation

1. **Clone or download this repository**

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the server**:
   ```bash
   npm start
   ```
   
   Or for development with auto-reload:
   ```bash
   npm run dev
   ```
5. **Open your browser**:
   Navigate to `http://localhost:8000`
